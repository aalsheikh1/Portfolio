# 🛡️ Adnan Alsheikh — Portfolio

**Cybersecurity & Info Assurance**

My personal website. I'm an information assurance graduate transitioning into ☁️ cloud security, and this site grows step by step as I learn and build.

## ✨ Features

- 🏠 **About page**: name, title, short intro, LinkedIn & GitHub links, skill pills (incl. Next.js, React, TypeScript, HTML, CSS, Git), and languages
- 🧭 **Top menu**: About · Experience · Education · Contact (current page highlighted in green)
- 💼 **Experience**: two roles shown as compact glowing bubbles with dates and locations, plus a 🧪 Projects section (this portfolio site)
- 🎓 **Education**: two degrees shown as ID-badge cards + certifications (CompTIA Security+ in progress)
- 🌐 **Cyber-themed background**: dark mode with a soft green & pink aurora glow
- 📬 **Contact form**: compact glass card + LinkedIn link
  - 👤 Full Name (required)
  - 📧 Email (required, must be valid)
  - 💬 Message (required, up to 2000 characters)
  - 📤 Send button that checks all fields (email delivery coming soon)
- 🛡️ **Shield favicon**
- 🚫 **Custom 404 page**: "ACCESS DENIED" with a link back home

## 🔒 Security

- 🧱 Security headers: `X-Content-Type-Options`, `X-Frame-Options`, `Referrer-Policy`, `Cross-Origin-Opener-Policy`, `Permissions-Policy`, `Strict-Transport-Security`
- 🙈 `X-Powered-By` header hidden
- 🔗 External links use `noopener noreferrer`
- 🔑 Secrets kept in `.env` files, never committed
- 🛡️ **Strict Content-Security-Policy**: a fresh nonce on every request; only trusted scripts run, which blocks XSS
