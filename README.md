# 🛡️ Adnan Alsheikh — Portfolio

**Cybersecurity & Info Assurance**

My personal website. I'm an information assurance graduate transitioning into ☁️ cloud security, and this site grows step by step as I learn and build.

## ✨ Features

- 🏠 **About page**: name, title, and a short intro
- 🧭 **Top menu**: About · Contact
- 🌐 **Cyber-themed background**: dark mode with a green grid and glow
- 📬 **Contact form**
  - 👤 Full Name (required)
  - 📧 Email (required, must be valid)
  - 💬 Message (required, up to 2000 characters)

## 🧰 Built With

- ⚛️ [Next.js](https://nextjs.org)
- 🔷 TypeScript
- 🎨 Tailwind CSS

## 🚀 Run It Locally

```powershell
cd portfolio
npm.cmd install
npm.cmd run dev
```

Then open 👉 http://localhost:3000
